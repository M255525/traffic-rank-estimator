網站流量排名比較工具

操作手冊

輸入一份網站名稱／網址清單，AI 會依其訓練知識估算這些網站近 12 個月的「相對熱門程度」趨勢，畫成折線圖比較，你也可以針對比較結果繼續提問。本工具沒有免費、可直接被瀏覽器呼叫的真實流量 API，所有數字都是 AI 主觀估算，不是任何真實測量值。

為什麼沒有真實流量數據？

SimilarWeb、Semrush 等網站流量分析服務都需要付費 API 金鑰才能取得數據，且大多不允許瀏覽器前端直接呼叫（CORS 限制）。目前沒有免費、可直接被本工具這種純前端小工具串接的官方流量來源。因此本工具改用 AI 依其訓練知識對這些網站的知名度與熱門程度做主觀估計，並在畫面上明顯標示這一點——請把結果當成「AI 的看法」，不是「真實測量的數據」。

外觀主題

右上角有 4 個圓形色塊，可以切換頁面底色：「午夜藍」「深紫夜」是深色主題，「晴空淺色」「暖米淺色」是淺色主題（一定會提供淺色選項）。切換後會記住你的選擇，下次打開會自動套用；若已經有比較結果，圖表與 KPI 顏色也會跟著新主題重繪。

操作步驟

  1. 在「網站名稱／網址清單」貼上想比較的網站，一行一個或用逗號分隔，最多 8 個；也可以點選下方 4 組快速範例
  2. 選擇「比較期間」（近6個月～近10年）與選填的「地區排名 KPI」地區
  3. 展開「AI 估算設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter）並填入你自己的 API 金鑰——這是必填，本工具沒有免金鑰的模式
  4. 選填最下方的「身分資訊」：姓名、組別、系所、學號——會顯示在最後下載/分享的截圖裡，方便老師或組員辨識
  5. 按「📊 開始比較」，AI 會回傳一份 JSON 資料，前端解析後畫成多線折線圖與每個網站的排名 KPI，並附上一句趨勢說明與整體比較總結
  6. 比較完成後，下方會出現「針對這次比較繼續提問」的問答框，可以直接輸入問題（例如「為什麼A的估算比B高」），AI 會參考這次的比較資料回答
  7. 比較結果卡片下方有「📷 下載截圖」「📤 分享」兩個按鈕，可以把整份結果（含姓名/組別/系所/學號）存成一張圖片或直接分享出去

比較期間怎麼選

期間從「近6個月」到「近10年」共 6 個選項。期間越長，時間點的單位會自動變粗，避免資料點過多讓圖表難讀：

  • 近6個月～近3年：以「月」為單位（最多 36 個點）
  • 近5年：以「季」為單位（20 個點）
  • 近10年：以「年」為單位（10 個點）

資料一律只估算到「目前日期往前 3 個月」為止，不含最近 3 個月。例如今天是 2026 年 9 月，估算的最後一個時間點會是 2026 年 6 月，不是 9 月——因為太接近現在的資訊，AI 難以準確掌握，刻意抓一個 3 個月前的結算基準點會讓估算更可靠。「比較期間」選的是從這個基準點往前回推多長，不是從今天往前回推。

圖表與 KPI 怎麼讀

  • 折線圖 Y 軸是「相對熱度指數」，固定 0-100，100 代表這組網站裡最熱門的那個時間點，是同一批網站之間的相對比較值，不是實際訪問量
  • 每個網站一條線，顏色與下方的網站說明卡片一致，把滑鼠移到線上可以看到當下各網站的數值
  • 每個網站說明卡片上方有兩個 KPI 小方塊：🌍「全球排名估計」一定會顯示；📍「（你選的地區）排名估計」只有在選了地區時才會顯示。兩者都是 AI 給的粗略量級文字描述（例如「全球約前 500 名」），不是精確名次，也不是任何第三方工具查到的真實排名
  • 如果某個網站的 AI 回覆格式異常（例如趨勢數字缺漏），該網站會被整筆略過並在圖表下方提示，不會影響其他網站正常顯示

問答面板怎麼用

比較完成後，AI 會把這次的比較資料（月份、各網站指數、趨勢說明、整體總結）記在對話中，接下來的每個問題都會連同這份資料一起送給 AI，所以可以直接問「為什麼」「差在哪裡」這類延伸問題，不需要重新描述一次資料。換一批網站重新比較時，之前的問答紀錄會清空重新開始。

問答紀錄只存在這次瀏覽器分頁的記憶體裡，重新整理頁面或關閉分頁就會消失，不會存到 localStorage 或任何伺服器。

下載截圖／分享

比較結果下方有兩個按鈕：

  • 📷 下載截圖：把整份比較結果（姓名/組別/系所/學號＋折線圖＋每個網站的排名 KPI＋趨勢說明）拍成一張 PNG 圖片存到裝置
  • 📤 分享：手機瀏覽器（例如 Android Chrome、iOS Safari）會直接跳出系統分享選單，可以傳到 LINE／Email／雲端硬碟等；桌機瀏覽器大多不支援分享功能，會自動改成下載圖片

截圖上方會顯示「身分資訊」那一列（姓名／組別／系所／學號），若沒有填任何一欄，會顯示「（未填寫姓名／組別／系所／學號）」。截圖前修改身分資訊欄位，畫面上的截圖預覽會即時更新，不需要重新按一次「開始比較」。

按下「下載截圖」或「分享」的當下，會自動把那個瞬間的日期與時間壓進「姓名」欄位裡（例如「姓名：王小明（下載時間：2026-09-08 16:23）」），就算沒填姓名也會顯示「姓名：未填寫（下載時間：…）」；產生圖片之後，畫面上會自動恢復成沒有時間戳記的正常顯示，不影響繼續操作。

截圖是在你的瀏覽器裡用 JavaScript（html2canvas）現場繪製產生，不會把圖片上傳到任何伺服器。

AI 估算設定（必填，需自備 API 金鑰）

  1. 選擇服務商；模型欄已列出幾個常用模型可直接選用，也可選「✏️ 自訂模型名稱」自行輸入其他模型 ID
  2. 填入你自己申請的 API 金鑰
  3. 按「開始比較」會直接從你的瀏覽器連線到你選擇的服務商官方 API
API 金鑰只存在你這台電腦的瀏覽器（localStorage），使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰。

隱私說明

  • AI API 金鑰只存在瀏覽器 localStorage，換一台電腦或清除瀏覽器資料就會不見
  • 按「開始比較」或送出問答時，內容會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器

# 網站流量排名比較工具

🔗 線上使用：<https://m255525.github.io/traffic-rank-estimator/>

輸入一份網站名稱／網址清單，AI 依其訓練知識估算這些網站近 12 個月的「相對熱門程度」趨勢，畫成多線折線圖比較，並可針對比較結果繼續提問。

- 純前端單頁網站，無需安裝、無後端、無序號授權。
- **需要 API 金鑰才能運作**：沒有免費、可直接被瀏覽器呼叫的真實流量 API，因此不像多數姊妹工具有「免金鑰也能用」的規則式備援模式。
- 選填 Claude／OpenAI／Gemini／OpenRouter 其中一家的 API 金鑰（BYOK，只存瀏覽器 localStorage）；每家服務商皆列出幾個常用模型可直接選用，也可自訂模型名稱。
- 最多同時比較 8 個網站，4 組快速範例一鍵帶入。
- 比較期間可選近6個月到近10年，期間越長自動改用季／年為單位，避免圖表資料點過多；估算一律只算到「目前日期往前 3 個月」為止，不含最近 3 個月，讓 AI 估算更可靠。
- 每個網站附「全球排名」與選填的「地區排名」KPI（粗略量級估計，例如「全球約前 500 名」）。
- 可選填姓名／組別／系所／學號，會顯示在下載截圖／分享的內容裡，方便課堂作業使用。
- 折線圖與說明皆明顯標示「AI 主觀估計，非真實流量數據」的警語。
- 比較完成後可在下方問答框針對這次結果繼續追問，AI 會記得這次的比較資料。
- 比較結果可一鍵下載成截圖 PNG，或用手機系統分享選單直接分享出去。
- 4 款底色主題可切換（右上角色塊），2 深 2 淺，選擇會記住；頂部有共用跑馬燈公告；可「加入主畫面」安裝成 App。完整操作說明見 [`manual.html`](./manual.html)。
